# ABNT Manual RAG Assistant

This project is a small Retrieval-Augmented Generation (RAG) assistant for
finding and explaining guidance in the ABNT normalization manual included in
the repository. It combines semantic search over the manual with answers
generated by the GitHub Copilot SDK, so responses can stay grounded in relevant
manual excerpts instead of relying only on general model knowledge.

## What it can do

- Extract and split the manual PDF into text passages.
- Create local text embeddings and search them with a FAISS vector index.
- Answer questions in Portuguese with the interactive Copilot SDK application.
- Search for relevant excerpts directly, without Copilot authentication.
- Use the `/abnt-manual` workspace skill in Copilot Chat to retrieve manual
  passages.

The app and skill provide a flexible question-and-answer interface, not
dedicated quiz or document-checking screens. The use cases below are example
prompts you can try with the assistant.

## Example use cases

### 1. Ask a question and get a source-grounded answer

Ask a focused question and request citations to the retrieved excerpts:

> Qual é a diferença entre referências e bibliografia? Responda com base no
> manual e cite os trechos usados.

The local index retrieves a passage that distinguishes documents cited in the
work from texts consulted but not included in it. A concise answer could be:

> Referências reúnem os documentos citados no trabalho; bibliografia reúne
> textos consultados que não fazem parte dele [Trecho 1].

### 2. Make a quiz to test your knowledge

Ask for a short quiz based only on the manual, and request that the answers be
withheld until you respond:

> Crie um quiz com cinco perguntas sobre o manual ABNT. Não mostre as respostas
> ainda. Depois que eu responder, corrija cada item, explique os erros e cite
> os trechos do manual.

For example, questions can cover the manual's distinction between references
and bibliography, the parts of an academic work, or the margin guidance for
long quotations. This is a prompt-driven study activity; the app does not have
a separate quiz mode or automatic scoring UI.

### 3. Find guidance for citations and references

Use the assistant to locate examples or clarify what information a reference
needs:

> Quais dados aparecem no exemplo de referência de um livro com um autor?
> Separe os elementos e cite o trecho correspondente.

You can also ask about citation rules, such as the guidance for quotations
longer than three lines. The assistant should explain only what its retrieved
passages support.

### 4. Build a formatting checklist

Ask for a checklist for a particular part of your work:

> Com base no manual, monte uma checklist para revisar a estrutura de um
> trabalho acadêmico, incluindo partes externas, internas e elementos
> pós-textuais. Cite os trechos usados.

The manual's indexed passages describe the external and internal parts of an
academic work and include examples of page layout and section formatting.

### 5. Review a short draft excerpt

Paste a paragraph or a reference and ask for possible issues to investigate:

> Compare este parágrafo com as orientações recuperadas do manual. Aponte
> possíveis problemas de formatação, explique o que não for possível confirmar
> e cite os trechos relevantes: [cole aqui o texto].

Treat this as a study aid, not a certification that an entire paper complies
with every ABNT standard. Check the cited passages and your institution's
requirements before submitting academic work.

## Requirements

- Python 3.11 or newer (the setup below uses Python 3.12.3).
- [`uv`](https://docs.astral.sh/uv/) to create the environment and install the
  pinned dependencies.
- The GitHub Copilot CLI and an account with Copilot access **only** if you
  want generated answers in the interactive app.

## Installation

Clone the repository and install its dependencies:

```bash
git clone https://github.com/Jadersonrilidio/abnt-manual-rag.git
cd abnt-manual-rag
uv venv --python 3.12.3 venv
source venv/bin/activate
uv pip install -r requirements.txt
```

On Windows, activate the environment with `venv\Scripts\activate` instead.

The first search or app run downloads the embedding model and builds a local
index from `pdfs/manual_de_normalizacao_abnt.pdf` if the local cache is not
available. The model and index are reused on subsequent runs.

## Use the workspace skill in Copilot Chat

Open the repository in VS Code and ask a question about the manual in Copilot
Chat, or invoke `/abnt-manual` directly. The skill retrieves passages from the
same local index and can answer without starting the interactive app or
authenticating the SDK runtime.

## Run the interactive assistant

The interactive app uses the GitHub Copilot SDK to generate answers. Sign in
through the Copilot CLI first:

```bash
copilot -i auth login
```

Then start the app:

```bash
python main.py
```

Ask a question at the prompt. Type `sair` to exit. You do not need an OpenAI API
key.

## Search the manual without Copilot

To retrieve the most relevant passages directly, run:

```bash
python .github/skills/abnt-manual/scripts/search.py \
  --query "Qual é a diferença entre referências e bibliografia?"
```

Use `--top-k N` to change the number of passages returned. This search command
does not require Copilot CLI authentication.

## How it works

`PdfProcessor` extracts and splits the PDF text. `EmbeddingService` creates
local multilingual embeddings, and `FaissVectorStore` saves and searches the
FAISS index. `ManualIndex` coordinates these components. For generated answers,
`CopilotAssistant` passes the retrieved passages to the Copilot SDK and asks it
to answer in Portuguese using those passages; `RagApplication` provides the
interactive console.

Answers depend on the contents of the included manual and on the passages
retrieved for each query. They are a practical aid for navigating that source,
not a substitute for checking current standards or institution-specific rules.
